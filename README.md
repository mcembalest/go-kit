# go-kit

Personal templates for building and sharing Go apps. Friends install each app directly with `go install`; they don't need go-kit.

## Use

Copy the [app template](templates/app) into your app's repo and follow [setup](SETUP.md).

| Command | Action |
| --- | --- |
| `make run` | Run locally |
| `make check` | Run checks |
| `make build` | Build the executable |
| `make release-check` | Check and preview release archives locally |
