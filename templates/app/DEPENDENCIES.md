# Dependencies

Fill this in for the app before sharing it.

| Stage | Requirements |
| --- | --- |
| Source installation | Go: state the minimum supported version |
| Development/checks | List tools and exact setup commands |
| Runtime | List external programs, supported versions, and authentication, or say none |
| Bundled | List embedded assets and included dependencies |

Explain what first launch sets up, what the user must install separately, and how
external tools get updated. App updates do not imply external dependency updates.
Keep optional example environments separate from core runtime requirements.

For a problem report: app `--version`, OS, reproduction steps, and relevant
external tool versions. Do not include credentials.
